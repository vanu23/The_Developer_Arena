# 🎯 Personal Introduction Program

A simple and friendly Python program that collects user information (name, age, hobby, etc.) and displays a customized welcome message.

## 📘 Project Overview
This project is part of a beginner-friendly Python learning series.  
The goal is to understand:
- Taking input from users using `input()`
- Storing data in variables
- Displaying formatted output using `print()` and f-strings
- Writing clean, readable code

## 📂 Code Structure

# Personal Introduction Program
# Day 1–5 Project | By Vanshika

# Asking user for details
name = input("What is your name? ")
age = input("How old are you? ")
hobby = input("What is your favorite hobby? ")
city = input("Which city do you live in? ")

# Displaying welcome message
print("\n🎉 Welcome", name + "! 🎉")
print(f"You are {age} years old, live in {city}, and love {hobby}.")
print("Glad to meet you! 😊")
