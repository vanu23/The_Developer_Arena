# Feature Engineering Documentation

## 1. Objective
Feature engineering was performed to extract meaningful information from existing variables and improve churn prediction performance.

---

## 2. Engineered Features Overview

### 2.1 Customer Lifetime Value (CLV)
**Formula:** 
CLV = Tenure × MonthlyCharges

**Purpose:**
- Represents total value generated by a customer
- High CLV customers are less likely to churn

---

### 2.2 Average Monthly Spend
**Formula:**
AvgMonthlySpend = TotalCharges / (Tenure + 1)

**Purpose:**
- Normalizes spending behavior
- Helps compare customers with different tenures

---

### 2.3 High Value Customer
**Logic:**

1 if MonthlyCharges > Median
0 otherwise

**Purpose:**
- Identifies premium-paying customers
- Useful for targeted retention strategies

---

### 2.4 Long Term Customer
**Logic:**

1 if Tenure ≥ 24 months
0 otherwise

**Purpose:**
- Captures customer loyalty
- Long-term customers typically show lower churn rates

---

### 2.5 Charges Ratio
**Formula:**

ChargesRatio = TotalCharges / (MonthlyCharges + 1)

**Purpose:**
- Measures consistency in billing
- Highlights anomalies or irregular payment patterns

---

## 3. Feature Selection Rationale
- Correlation analysis was used to detect redundant features
- Random Forest feature importance identified top predictive features
- Engineered features ranked high in importance, validating their usefulness

---

## 4. Impact on Model Performance
- Improved model interpretability
- Increased predictive power
- Reduced reliance on raw features alone

---

## 5. Conclusion
The engineered features significantly enhance the dataset by capturing customer behavior, value, and loyalty patterns. These features contribute directly to improved churn prediction accuracy.
