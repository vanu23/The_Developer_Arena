# 📊 Sales Data Analysis Project

## Project Overview
This project performs a complete end-to-end data analysis on a sales dataset.
It includes data loading, cleaning, analysis, visualization, and reporting
to derive meaningful business insights.

## Objectives
- Analyze overall sales performance
- Identify best-selling products
- Understand sales trends over time
- Present insights using visualizations

## Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Setup Instructions
1. Clone the repository
2. Navigate to the project directory
3. Install dependencies: pip install -r requirements.txt
4. Open and run `analysis.ipynb`

## Folder Structure
- `data/` – Raw and cleaned datasets
- `visualizations/` – Generated charts
- `report/` – Final analysis report
- `analysis.ipynb` – Complete analysis notebook

## Key Insights
- Total sales and average sales were calculated
- Best-selling product identified
- Sales patterns visualized using bar and line charts
