# 🎓 Student Grade Calculator

A simple Python program that takes a student's marks and returns their grade along with an encouraging message.

## 📌 Project Overview
This project is part of a beginner-friendly Python series.  
It helps students learn:
- Input handling
- Conditional logic (if-elif-else)
- Functions
- Input validation
- Looping for error handling

The program:
- Accepts student name
- Accepts marks (only between 0–100)
- Determines grade based on rules
- Returns a personalized message

---

## 🛠️ Features
✔ Input validation using **while loop**  
✔ Grading logic using **if-elif-else**  
✔ Custom **function** for grade calculation  
✔ Encouraging messages for each grade  
✔ Clean and readable code

---

## 🧠 Grading Criteria
| Marks Range | Grade |
|------------|--------|
| 90–100     | A |
| 80–89      | B |
| 70–79      | C |
| 60–69      | D |
| 0–59       | F |
